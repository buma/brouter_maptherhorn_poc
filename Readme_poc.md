## What is this?

This is POC to use Maptherhorn elevation in brouter

First [this](https://github.com/buma/Maptherhorn_brouter_poc) is used to get maptherhorn tiles in correct format
Then [staatcoding](https://github.com/abrensch/statcoding) has to be installed locally

And in PosUnifier.java path to tiles has to be provided
Then it will use this tiles if it finds tile for coordinate otherwise it'll fallback to SRTM
